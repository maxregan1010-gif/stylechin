# راهنمای انتشار نسخه ۱.۴ استایل‌چین

این پروژه یک برنامه Node.js + Express است. GitHub کد را نگه می‌دارد و Render سرور `server.js` را اجرا می‌کند.

## ۱) قراردادن نسخه جدید روی GitHub

1. فایل ZIP نسخه ۱.۴ را استخراج کن.
2. وارد مخزن قبلی `stylechin-ai` در GitHub شو.
3. فایل‌های نسخه جدید را در صفحه اصلی مخزن بارگذاری کن و فایل‌های قدیمی را با نسخه جدید جایگزین کن؛ پوشه `public` هم باید جایگزین شود.
4. فایل `.env.example` را بارگذاری کن، اما فایل واقعی `.env` را هرگز در GitHub قرار نده.
5. روی `Commit changes` بزن.

## ۲) به‌روزرسانی متغیرها در Render

1. وارد https://render.com شو و سرویس `stylechin-ai` را باز کن.
2. به بخش **Environment** برو.
3. این چهار متغیر را بررسی کن:

| Key | Value |
|---|---|
| `CLOUDFLARE_ACCOUNT_ID` | شناسه حساب فعلی Cloudflare |
| `CLOUDFLARE_API_TOKEN` | توکن فعلی Cloudflare |
| `CLOUDFLARE_TEXT_MODEL` | `@cf/google/gemma-4-26b-a4b-it` |
| `CLOUDFLARE_IMAGE_MODEL` | `@cf/leonardo/phoenix-1.0` |

برای تعویض مدل‌ها نیازی به ساخت توکن تازه نیست؛ همان توکن فعلی Workers AI قابل استفاده است، به شرط آن‌که مجوز Workers AI لازم را داشته باشد.

4. مقدارها را ذخیره کن.
5. از بخش Events گزینه **Manual Deploy** و سپس **Deploy latest commit** را انتخاب کن. اگر Auto Deploy روشن باشد، بعد از Commit هم امکان انتشار خودکار وجود دارد.

## ۳) بررسی انتشار

آدرس سایت Render را باز کن. سپس این مسیر را هم بررسی کن:

`https://YOUR-SERVICE.onrender.com/api/status`

در پاسخ، مقدارهای `textModel` و `imageModel` باید به مدل‌های جدید اشاره کنند و `mode` باید `configured` باشد.

## ۴) اجرای محلی در ویندوز

در پوشه پروژه PowerShell را باز کن:

```powershell
npm.cmd install
npm.cmd start
```

سپس `http://localhost:3000` را باز کن. برای اجرای محلی، یک کپی از `.env.example` بساز، اسم کپی را `.env` بگذار و Account ID و API Token خودت را در آن قرار بده.

## ۵) تغییرات انتخاب شلوار و تصویر

- در فرم دیگر فهرست انتخاب شلوار وجود ندارد؛ خود مدل پیشنهاددهنده از بین انواع شلوار، گزینه مناسب را انتخاب می‌کند.
- نوع انتخاب‌شده در `items.bottomType` ثبت می‌شود و همان شناسه و توضیح نهایی به بخش تصویرسازی فرستاده می‌شود.
- خطای قبلی تصویر به این دلیل بود که Phoenix 1.0 خروجی JPEG خام می‌دهد، نه JSON دارای `result.image`. نسخه ۱.۴ پاسخ باینری JPEG/PNG/WebP را مستقیم می‌خواند و در کنار آن پاسخ JSON/base64 را هم پشتیبانی می‌کند.
- اندازه‌ی معمول لباس به‌صورت اختیاری به فرم اضافه شده؛ به‌جای برچسب‌زدن به حجم بدن، فقط برای تناسب و راحتی پوشاک در نظر گرفته می‌شود.

## ۶) نکته درباره سهمیه و هزینه

Workers AI در طرح رایگان ۱۰٬۰۰۰ Neurons در روز دارد. این سهمیه بین فراخوانی‌های متن و تصویر مشترک است و در صورت مصرف کامل، درخواست‌های بعدی تا بازنشانی سهمیه انجام نمی‌شوند. مصرف دقیق به مدل، اندازه تصویر و تعداد گام‌های تولید بستگی دارد؛ رایگان بودن به معنی نامحدود بودن نیست.

## ۷) محدودیت تصویرسازی

Phoenix 1.0 نسبت به دستور تصویر راهنمای منفی و مقدار guidance می‌گیرد؛ این موارد احتمال جایگزینی لباس‌ها را کمتر می‌کنند، اما هیچ مدل متن‌به‌تصویر تضمین نمی‌کند که همه جزئیات یک ست را بدون خطا بازسازی کند.

## امنیت

- هرگز توکن Cloudflare را در HTML، JavaScript سمت مرورگر یا GitHub قرار نده.
- کلیدها فقط در فایل `.env` محلی یا بخش Environment در Render باشند.
- اگر کلید در مخزن عمومی منتشر شد، فوراً آن را در Cloudflare باطل کن و کلید تازه بساز.
